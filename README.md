# ⚡ GridVision AI

GridVision AI is an AI-powered Digital Twin based Smart Substation Monitoring System developed to simulate and monitor electrical substations in real time.

## 🚀 Features

- Live Dashboard
- Python Digital Twin
- Flask Backend API
- Real-Time Voltage Monitoring
- Real-Time Current Monitoring
- Frequency Monitoring
- Temperature Monitoring
- Automatic Breaker Trip Simulation
- AI-Based Fault Prediction
- Dynamic Notifications
- Dynamic Event Log
- Responsive Web Dashboard

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- GitHub

## 🧠 Project Architecture

Digital Twin (Python)
↓
Flask Backend API
↓
Web Dashboard

AI Prediction | Notifications | Event Log
